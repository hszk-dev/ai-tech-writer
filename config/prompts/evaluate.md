## 評価基準

6つの観点で1〜10のスコアをつけてください：

1. **構造性 (structure_score)**: 見出しの階層が適切か、論理的な流れになっているか
2. **技術的正確性 (accuracy_score)**: 内容は正確か、コードは動作するか
3. **可読性 (readability_score)**: 初心者にもわかりやすいか、説明は丁寧か
4. **実用性 (practicality_score)**: 読者がすぐに実践できる内容か、具体例があるか
5. **新規性 (novelty_score)**: 既存記事にない新しい視点・情報があるか
   - 未カバー領域: 既存記事であまり触れられていない内容か
   - 新しい視点: 既知のトピックでも独自の切り口があるか
   - 最新情報: 2025年時点での最新のベストプラクティスか
   - 実体験ベース: 他では得られない実践知見があるか
6. **バズ可能性 (buzz_score)**: Zenn/Qiitaでバズりそうか
   - タイトルの引き: 具体的数字、意外性、解決感があるか
   - トレンド性: 2025年の技術トレンドとの合致
   - 共有性: SNSで共有したくなる要素があるか
   - 議論喚起: コメントや議論を呼びそうな内容か

## 回答形式

必ず以下のJSON形式で回答してください：

```json
{
  "overall_score": 7.5,
  "structure_score": 8.0,
  "accuracy_score": 7.0,
  "readability_score": 7.5,
  "practicality_score": 7.5,
  "novelty_score": 7.0,
  "buzz_score": 7.0,
  "feedback": "具体的な改善点や良い点のコメント",
  "buzz_improvement": "バズるためにはこうすると良いというアドバイス"
}
```

## スコア計算

`overall_score`は6つのスコアの加重平均です：
- 構造性: 10%
- 技術的正確性: 15%
- 可読性: 10%
- 実用性: 15%
- **新規性: 25%**
- **バズ可能性: 25%**

新規性とバズ可能性で合計50%を占めます。

## 注意点
- スコアは0.5刻みで評価してください
- feedbackは100文字以内で簡潔に
- buzz_improvementは具体的なアクションを提案
