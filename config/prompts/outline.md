## タスク
上記の情報を元に、詳細な記事アウトラインを作成してください。

以下のJSON形式で回答してください：

```json
{
  "introduction": "はじめにセクションで書く内容の概要（2-3文）",
  "sections": [
    {
      "heading": "セクションの見出し",
      "key_points": [
        "このセクションで説明するポイント1",
        "このセクションで説明するポイント2",
        "このセクションで説明するポイント3"
      ],
      "code_needed": true,
      "estimated_words": 300
    }
  ],
  "conclusion_points": [
    "まとめで触れるポイント1",
    "まとめで触れるポイント2",
    "今後の発展や参考リソース"
  ]
}
```

## 注意点
- 各セクションは独立して理解できるように設計してください
- コードが必要なセクションには `code_needed: true` を設定してください
- 論理的な流れを意識してください（基礎→応用、問題→解決）
- 全体で2000-4000文字程度になるよう調整してください
