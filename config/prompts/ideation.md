## タスク
上記のトピックについて、Zenn/Qiita向けの技術記事のアイデアを生成してください。

以下のJSON形式で回答してください：

```json
{
  "title": "記事タイトル（具体的で魅力的なもの）",
  "emoji": "記事を表す絵文字1つ",
  "topics": ["タグ1", "タグ2", "タグ3", "タグ4", "タグ5"],
  "target_audience": "想定読者（例：Reactの基本を理解している中級者）",
  "problem_to_solve": "この記事が解決する課題",
  "key_takeaways": [
    "読者が学べること1",
    "読者が学べること2",
    "読者が学べること3"
  ],
  "suggested_sections": [
    "はじめに",
    "セクション2のタイトル",
    "セクション3のタイトル",
    "実装例",
    "まとめ"
  ]
}
```

## 注意点
- タイトルは具体的で、読者の興味を引くものにしてください
- topicsは5つまで、関連性の高いものを選んでください
- suggested_sectionsは5〜7個程度にしてください
- 「やってみた」だけでなく、なぜそうなるのかの解説を含む構成にしてください
